# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.1] - 2025-05

### Added
- Full site adaptation guide covering Americas, Europe, Japan, Southeast Asia, and Middle East marketplaces
- Multi-competitor comparison workflow with merged SWOT analysis
- 30-minute quick survey workflow for time-constrained research
- Blank fillable research template for manual data entry

### Changed
- Restructured 7-module output templates with standardized table formats
- Improved traffic structure analysis with 3-tier decomposition (organic/paid -> search/recommendation -> tag-level)
- Enhanced ad strategy module with 5 ad types (SP/SB/SBV/SD/SDV) coverage

### Fixed
- Site-specific pricing display format issues
- Keepa data interpretation for promotion duration accuracy

---

## [1.0] - 2025-04

### Added
- Initial release with 7 core analysis modules
- Basic info research (brand, ASIN, price, rating, sales, BSR, conversion)
- Traffic structure analysis (organic vs paid, search vs recommendation)
- Advertising strategy analysis (SP, SB, SBV, SD, SDV)
- Promotion strategy analysis via Keepa price history
- Creative assets breakdown (images, videos by placement)
- Off-site traffic research (website, Deal sites, social media)
- SWOT analysis and actionable monthly promotion checklist
- Standardized Markdown report output format
- Support for all Amazon global marketplaces
