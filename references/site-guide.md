# 站点适配指南

不同站点的消费者行为、平台规则和推广渠道差异显著。以下为各集群站点的重点调整指南。

---

## 欧美站（美/加/英/德/法/意/西）

**核心特征：** 消费者看重品牌和功能，站外渠道成熟

| 调整维度 | 具体操作 |
|---------|---------|
| 站外引流 | 重点调研 YouTube 红人测评、各站点主流 Deal 站（如美国 Slickdeals、德国 Mydealz、法国 Dealabs） |
| 广告策略 | SD/SDV 展示广告占比通常高于亚洲站点，需重点关注 DSP 投放 |
| 素材体系 | 视频素材权重极高，主图视频几乎标配；A+ 内容精细化程度高 |
| 促销节奏 | 重点关注 Prime Day（7月）、黑五网一（11月）等大促节点的历史促销策略 |
| 合规注意 | 关注欧盟 EPREL 能效标签、WEEE、包装法等特殊要求 |

---

## 日本站

**核心特征：** 消费者极度重视细节，促销频率高，价格敏感度适中

| 调整维度 | 具体操作 |
|---------|---------|
| 促销策略 | 重点关注高频率的限时促销和积分活动，日本站促销频率显著高于欧美站 |
| 素材细节 | 产品图片必须展示大量细节图和使用场景，日本消费者购买决策依赖详细图文 |
| 价格带 | 关注竞品是否使用划线价策略（市场价 + 促销价），这是日本站常见打法 |
| 评论分析 | 日本消费者评论更加细致，负面评论中关于包装和说明书的抱怨需要特别关注 |
| 站外渠道 | 重点调研 Twitter/X、LINE 等日本主流社媒，Amazon.co.jp Points 体系 |

---

## 东南亚站（新加坡/泰国/越南等）

**核心特征：** 价格敏感度高，物流是关键差异化因素

| 调整维度 | 具体操作 |
|---------|---------|
| 基础信息 | 重点关注竞品的配送方式（FBA vs 自发货）和时效承诺 |
| 价格带 | 分析竞品价格底线和折扣极限，东南亚站价格战更激烈 |
| 流量结构 | 关注竞品是否通过低价引流 + 变体组合提客单价 |
| 促销策略 | 重点关注日常低价 + 闪购（Flash Deal）的频次 |

---

## 中东站（阿联酋/沙特）

**核心特征：** 广告投放和支付方式是差异化重点

| 调整维度 | 具体操作 |
|---------|---------|
| 广告策略 | 重点关注竞品的广告投放力度和关键词出价水平，中东站广告竞争相对低但CPC可能较高 |
| 支付方式 | 关注是否提供货到付款（COD）选项，这在中东是重要转化因素 |
| 素材体系 | 关注阿拉伯语的 Listing 本地化质量、文化适配性 |
| 促销节奏 | 重点关注斋月、白色星期五等中东特有促销节点的历史策略 |
